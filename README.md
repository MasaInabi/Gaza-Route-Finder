# Gaza Route Finder

A Java application that finds the shortest path between cities in Gaza using Dijkstra's algorithm and displays the route visually on a map.

## Features

- Find the shortest path between two cities
- Calculate the total distance in kilometers
- Visualize the selected route on the map
- Choose source and target cities
- Add a new city with latitude and longitude
- Connect new cities to neighboring cities
- Interactive Java GUI

## Algorithm

The project uses **Dijkstra's Shortest Path Algorithm** to calculate the shortest route between the selected source and target cities.

## Technologies

- Java
- JavaFX
- Dijkstra's Algorithm
- Graph Data Structure

## How to Run

1. Clone or download the project.
2. Open it in Eclipse or another Java IDE.
3. Make sure JavaFX is configured.
4. Run the main application class.
5. Select a source and target city.
6. Click **Run Dijkstra** to display the shortest path and distance.
